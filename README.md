Data Center Academy — Technician II Crash Course

A free, interactive study and practice app designed to help prepare for Data Center Technician II responsibilities.

Features

- Learning modules: Data center fundamentals, safety, ESD, server hardware, networking, OSI model, fiber optics, RAID, Linux, rack infrastructure, and troubleshooting.
- Virtual rack simulator: Explore rack components and learn their functions.
- Linux practice terminal: Practice common Linux commands in a simulated environment.
- Troubleshooting missions: Work through practical data center scenarios.
- Knowledge checks: Test your understanding as you progress.
- Interview preparation: Review technical concepts and organize interview answers.
- Progress tracking: Save learning progress locally on your device.
- Offline support: Access the app after its initial load when supported by your browser and cached files.

Getting Started

1. Open the published GitHub Pages website.
2. Start with the Foundations module.
3. Work through the learning modules in order.
4. Practice with the virtual rack simulator.
5. Complete the troubleshooting missions and knowledge checks.
6. Review the interview preparation section.

Publishing with GitHub Pages

1. Open the repository's Settings.
2. Select Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select the "main" branch.
5. Select the "/ (root)" folder.
6. Save your settings.

The expected website address is:

https://riskibiznis.github.io/datacenter-academy/

Installing on Android

1. Open the published website in Chrome.
2. Open Chrome's three-dot menu.
3. Select Install app or Add to Home screen, depending on the available option.
4. Follow the prompts to add the app to your device.
